# Contributing to Data Science Portfolio

Thank you for your interest in contributing to this data science portfolio! This repository contains projects demonstrating data analysis, machine learning, and visualization skills.

## 🐛 Reporting Issues

If you find bugs, errors in analysis, or broken functionality, please open an issue with:
- A clear, descriptive title
- Description of the problem and expected behavior
- Steps to reproduce (which project, notebook, commands)
- Environment details (OS, Python version, library versions)
- Error messages or stack traces

## 💡 Suggestions

Contributions can include:
- Bug fixes in code
- Improved data analysis or visualizations
- Code optimization
- Better documentation or explanations
- Additional features or analysis
- Updated dependencies
- Corrections to methodology

## 🔧 How to Contribute Code

### Workflow
1. Fork the repository and create a feature branch
2. Make your changes following existing code style
3. Test your changes (run notebooks, scripts)
4. Update documentation if needed
5. Open a Pull Request with a clear description

### Coding Standards
- Follow PEP 8 style guidelines for Python
- Add docstrings to functions
- Include comments explaining analysis steps
- Use meaningful variable names
- Keep code modular and reusable

### Testing
- Run all code to ensure it works
- Verify data processing produces correct results
- Check that visualizations render properly
- Test with sample data if possible

### Jupyter Notebooks
- Clear all outputs before committing
- Ensure notebooks run from top to bottom without errors
- Include markdown cells with explanations
- Keep notebooks focused and well-organized

## 📝 Pull Request Checklist
- [ ] Code runs without errors
- [ ] Documentation updated
- [ ] Follows project style
- [ ] Clear commit messages
- [ ] Analysis is methodologically sound
